# Installation

Welcome to the installation guide for **scAnalyzer**. Follow the steps below to set up the library on your local machine.

## Prerequisites

Before you begin, ensure you have the following installed:
- Python 3.8 or higher.
- `git` command line tool.

## Step-by-step Guide

1. **Install scAnalyzer using pip:**
   Install scAnalyzer using `pip`:
```bash
   pip install scAnalysis
   ```

You are now ready to start analyzing your single-cell data with scAnalyzer.
